# Abandoned but not Forgotten

An interactive educational atlas about NASA spacecraft, rovers, and landers that remain on the Moon and Mars. Created for the NASA Space Apps Challenge 2026.

## Run locally

Open `index.html` in a modern browser. The static site needs no server, build step, backend, or dependencies. NASA-hosted images and optional web fonts need internet access; artifact cards have visual fallbacks if an image fails.

## Explore

- Search the archive and filter by destination or mission type.
- Open an artifact for its mission history, discoveries, current status, NASA source, and reported location.
- Navigate the interactive timeline using its milestones or arrow controls.
- Switch the Moon/Mars atlas and select markers for the corresponding mission information.
- Use keyboard focus, Enter/Space, and Escape for common interactions.

## Location and accuracy

The location atlas is schematic and not to scale. Marker placement is illustrative and does not claim coordinates. Site names are based on NASA sources. The Apollo descent stages and rovers are grouped in mission records; individual Apollo sites appear in the atlas. The Surveyor record summarizes the program, including missions that did not successfully land.

## Image and mission sources

Images are requested from NASA's Image and Video Library at `images-assets.nasa.gov`. Each artifact detail includes its mission reference. Sources include NASA's Human Artifacts on the Moon catalog, NASA Science mission pages, NASA NSSDC, NASA/JPL-Caltech, and NASA/GSFC. See [SUBMISSION.md](SUBMISSION.md) for the full reference list and disclosure.
