# Abandoned but not Forgotten

An interactive educational atlas about NASA spacecraft, rovers, and landers that remain on the Moon and Mars. Created for the NASA Space Apps Challenge 2026.

## Run locally

Open `index.html` in a modern browser. The site uses plain HTML, CSS, and vanilla JavaScript; it needs no server, build step, backend, or dependencies. An internet connection is needed for NASA-hosted images and optional web fonts. If an image cannot load, its card falls back to a mission-colored visual.

## Explore

- Search artifacts and filter by destination or mission type.
- Select any artifact card for mission history, why it remains, discoveries, status, and NASA source links.
- Navigate the interactive timeline with its milestones or arrow controls.
- Switch the Moon/Mars atlas and select markers to read about known landing regions.
- Use keyboard focus, Enter/Space, and Escape for accessible interactions.

## Location and accuracy notes

The map is schematic and explicitly not to scale. Marker placement is illustrative only and is not a coordinate claim. NASA-reported site names are shown in marker details. The Apollo descent stages and Apollo rovers are grouped into mission records; individual landing sites are listed in the atlas. NASA mission pages and the NASA human artifacts catalog are linked from each record. The Surveyor record summarizes the program; not every Surveyor spacecraft landed successfully.

## Image credits

Images are requested from the NASA Image and Video Library (`images-assets.nasa.gov`). The site displays NASA/JPL/Caltech and NASA/GSFC credit context. Mission facts and destination information are sourced from NASA mission pages, NASA Science, and the NASA human artifacts catalog linked in the artifact details.
