## Detailed description

Abandoned but not Forgotten is a responsive educational website about the machines and equipment that remain where lunar and Martian exploration happened. The archive covers Apollo Lunar Module descent stages, Lunar Roving Vehicles, the Surveyor program, Mars Pathfinder, Sojourner, Spirit, and Opportunity. Each record explains its mission, destination, year, purpose, scientific contributions, present status, and reported site.

The interactive timeline links key milestones from Surveyor 1’s 1966 lunar landing through the 2024 end of Ingenuity’s flight mission. The location atlas lets visitors switch between the Moon and Mars and select mission-site markers. Its marker positions are explicitly schematic and not coordinate claims; site names are drawn from NASA sources. Artifact records include links to NASA mission references.

The project highlights scientific legacy, preservation of historically significant sites, lessons for future exploration, and the need to plan responsibly for long-lived hardware and debris.

## NASA data, references, and media

This project uses NASA-published mission histories and catalog information as its factual references. It does not query a live API or process a separate raw science dataset. Images are requested from NASA’s Image and Video Library (`images-assets.nasa.gov`).

- [NASA: Human Artifacts on the Moon](https://www.nasa.gov/wp-content/uploads/static/history/humanartifacts.html)
- [NASA Science: Apollo Landing Sites](https://science.nasa.gov/resource/apollo-landing-sites/)
- [NASA NSSDC: Surveyor Project](https://nssdc.gsfc.nasa.gov/planetary/lunar/surveyor.html)
- [NASA Science: Mars Pathfinder](https://science.nasa.gov/mission/mars-pathfinder/)
- [NASA/JPL: Mars Pathfinder and Sojourner](https://www.jpl.nasa.gov/missions/mars-pathfinder-sojourner-rover/)
- [NASA Science: Spirit](https://science.nasa.gov/mission/mer-spirit/)
- [NASA Science: Opportunity](https://science.nasa.gov/mission/mer-opportunity/)
- [NASA/JPL: Ingenuity](https://www.jpl.nasa.gov/missions/ingenuity/)
- NASA Image and Video Library: https://images.nasa.gov/

Image credit: NASA, NASA/JPL-Caltech, or NASA/GSFC as applicable to the source image. Individual mission citations are also available from the artifact detail views in the site.

## Challenge fit

The project answers “Abandoned but not Forgotten” by making the locations, histories, and ongoing scientific and cultural value of off-world artifacts understandable to a general audience. It calls out schematic mapping and links factual claims to NASA sources so that exploration records can be revisited responsibly.

## How to run

Open `index.html` in a modern browser. The static website needs no build step, server, backend, or dependencies. Internet access is needed for NASA-hosted images and optional web fonts. `demo.html` is a seven-slide project overview that also works offline apart from its NASA image.
